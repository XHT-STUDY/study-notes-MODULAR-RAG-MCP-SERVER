## 0. 先看清你的牌面：IANG 改变了一切

以下规则来自入境事务处官网（IANG 页面，2026-04 版本）：

1. **免担保**：IANG 期间工作没有任何行业/雇主限制，**雇主雇你不需要办任何签证手续**——和雇本地人一样。这是你对香港雇主最大的差异化优势，内地候选人普遍卡在"要担保"这一关。
2. **换工作完全自由**：IANG 期间自由入职、自由跳槽，无需入境处批准（这是专才 GEP 做不到的）。
3. **续签需要就业**：到期续签（3+3 年模式）时必须已获得"学位持有人通常受雇级别、市场水平薪酬"的工作。续签窗口 = 到期前 3 个月内提出、至少提前 6 周，处理约 2-3 周。
   - 换算成你的时间线：**2027-10 前必须已就业**。你三个月计划的目标（2026-12 拿 offer）留了 10 个月的安全边际——既不慌，也别拖。
4. **永居时钟（2026-09-08 核实修正）**：7 年"连续通常居住"只计**合法在港**的期间，且必须**连续、紧贴申请日之前**（访客身份不算；短期离港度假/出差不算断）。你的学生签与 IANG 之间有数月无签证间隔——按现行口径构成**中断**，永居时钟从 **IANG 激活入境日重新起算**（约 2026 年初 + 7 年 ≈ **2033 年初**，此前文档写的 2031 不成立）。由此产生两条纪律：① 从今往后任何换签/续签必须无缝衔接，再断一次时钟就再往后推；② 拿到工作后要真实以港为居住地（长期拿香港签证但常住内地，会在永居申请时被审查"香港是否仍是你的惯常居所"），并从现在开始留存 MPF、税单、租约、工资记录——举证责任在申请人。依据：入境处[居留权资格页](https://www.immd.gov.hk/hkt/services/roa/eligible.html)、[社区法网解释](https://www.clic.org.hk/cn/topics/immigration/hk_permanent_residence/q1)。

**一句话定位（所有材料统一用这个口径）**：

> 把 LLM 的原始能力变成可靠、可评测、可维护的生产系统——RAG、后训练、任务型 Agent 三条路线都在生产环境落地过，带着评测闭环做迭代。香港院校毕业，持 IANG，随时到岗，零签证成本。

## 3. 英语与粤语提升（三个月，优先级差距极大）

### 3.1 英语：ROI 是粤语的 10 倍，面试就是英语

**目标定位**：不是"流利英语"，是**面试英语**——技术内容准确、结构清晰、能稳定输出 45 分钟、听得懂带口音的印度/欧洲面试官。这个目标 3 个月可达。

**每日 routine（合计约 1 小时，与刷题并行）**：

| 时段 | 内容 |
|---|---|
| 通勤/碎片 30-45 min | 英文技术输入：Latent Space / Practical AI 播客、Hacker News、Sebastian Raschka 博客、论文 abstract |
| 每晚 15 min | 录音复述一个项目故事（见下 story bank），回听、纠错、重录 |
| 每周 2 次 30 min | italki / Cambly 上约"interview English"导师做真人对话（约 HK$80-150/节，性价比最高的单项投入） |
| 随时 | 和 AI 语音对话做英文模拟面试：把你的简历发给它，让它扮演香港面试官追问 |

**Story bank（第 1 周建好，全部英文写出来）**，5 个故事覆盖全部行为面和技术深挖：

1. Hybrid search 的选型与降级（RRF 融合、reranker 失败回退——约束→取舍→数据→结果）
2. 评测闭环驱动迭代（黄金集、Hit Rate/MRR、怎么发现并修复一次检索质量问题）
3. LoRA 多模态微调的取舍（为什么 LoRA 不全参、数据配比、效果与成本）
4. 任务型 Agent 的设计（为什么不是 LLM-loop、工具接口怎么设计、失败模式）
5. **一个失败故事**（项目翻车/延迟/误判，讲清复盘和改变——行为面必考，最忌讳没有）

**术语表达清单**：第 1 周整理一份 ML/LLM 术语的英文本（attention / KV cache / LoRA rank / hallucination / grounding / eval harness / tool calling / trajectory…），确保嘴上能说而不只是认识。

**里程碑**：W4——英文自我介绍 + 任一项目讲满 10 分钟；W8——能应对连续英文追问不卡壳；W12——全英文 mock 面试通过（AI + 真人各一次）。

### 3.2 粤语：生存级即可，不要过度投入

事实：多数技术岗 JD 写"流利中文（粤语更佳）"，面试语言基本是英语；粤语不是硬门槛。三个月的合理目标：**听得懂日常寒暄、会礼貌问候、面试时能大方说"basic Cantonese, actively learning"**（这句话本身是加分项——表明你打算留下）。

- 每天 20 分钟：words.hk（粤语词典）、YouTube 粤语教学频道、TVB 剧集开字幕精听。
- 重点学：数字/时间/钱、办公问候、"唔该/多谢/早晨"、自我介绍一句。
- 别报班、别刷教材——把时间留给英语和刷题。

## 4. 项目包装（简历与叙事）

### 4.1 香港简历规范（和内地差异）

- **1-2 页，英文版为主**；中文版备用（中资驻港/BOSS直聘用）。
- **第一屏顶部放签证状态行**（这是香港简历对你最重要的一行）：
  > **Visa: IANG holder — valid until Jan 2028. No sponsorship required. Available immediately.**
- Education 放上半页：香港学位既解释身份又给本地资质信号。
- 不放照片、不放年龄婚姻（香港无简历照片惯例的硬要求，写了反而引入偏见）。
- 联系方式：+852 号码（办一个储值卡）+ WhatsApp（香港 HR 默认用 WhatsApp 沟通，回复要快）。
- Application form 里 expected salary / notice period 按第 7 节口径填。

### 4.2 叙事主线：四段经历收拢成一个问题域

不要写成"做过平台、做过RAG、做过微调、做过Agent"（四个浅尝辄止），统一到：

> 我做的事情一直是：把 LLM 的原始能力变成**可靠、可评测、可维护**的生产系统。RAG/微调/Agent 是三种解法——注入知识、注入能力、注入行动——我三条路线都在生产里走过，所以我知道什么约束下选哪条，以及怎么证明它有效。

每条 bullet 的结构（你 RESUME.md 里已经是这个结构，保持并英文化）：**约束 → 决策与备选取舍 → 量化结果 → 失败/降级路径**。

### 4.3 三个定制版本（同一事实，不同侧重）

| 版本 | 强调 | 弱化 |
|---|---|---|
| 银行版 | 平台工程、可靠性、降级、合规友好的可观测性、TDD/测试 | 模型训练细节 |
| 初创版 | 端到端全栈、速度、多角色、成本意识 | 企业级流程 |
| 大厂驻港版 | 算法深度、微调细节、Agent 工程化、评测方法论 | 平台/运维 |

### 4.4 作品集

你的 RAG MCP Server 项目就是现成 portfolio：README 英文化、加一张架构图、放 2-3 个核心设计决策的说明（为什么 RRF、为什么两级哈希、降级怎么做的）。面试官点开 GitHub 的 90 秒内要能看懂它做了什么、做得有多认真。

### 4.5 常见坑

- 罗列技术栈名词而不讲故事（香港 HR 和内地一样先扫关键词，但技术面看的是决策叙事）。
- 量化数字注水（RESUME.md 里已标注哪些建议值，面试被追问时坦承是估计，讲清方法论）。
- 毕业后至今的空档：如果这段时间在做项目/学习，如实包装成"systematic upskilling + 开源项目"（这个仓库就是证据）；一两句带过，不解释过多。

## 5. 面试准备

### 5.1 编程（所有雇主类型都考）

- 量：**12 周 120-140 题**，以 LeetCode Medium 为主（银行难度即中等；量化加练概率/数学题）。
- 题单：NeetCode 150。周计划：W1-2 数组/哈希/双指针 → W3-4 滑窗/栈/二分 → W5-6 树/图/BFS-DFS → W7-8 DP 基础 → W9-10 堆/回溯 → W11-12 混合限时模拟。
- 练的时候**边写边用英文说思路**（narrate your thinking）——一石二鸟，面试英语同步成型。

### 5.2 ML/LLM 八股（英文版高频题清单）

- Transformer / attention 机制、KV cache、位置编码
- LoRA 原理与秩选择、什么场景微调不如 RAG、微调不如 prompt
- RAG 全链路：chunking 策略、hybrid search 为什么、RRF 公式与 k 的作用、rerank 时机、评测（Hit Rate/MRR/Ragas）
- Agent：ReAct、tool calling 设计、输出不可控怎么办、多步任务的失败模式与恢复
- 幻觉：成因分类与缓解手段（grounding、citation、guardrail）
- 评测方法学：怎么建黄金集、LLM-as-judge 的坑

这些是你的主场，第 2-4 周把它们写成英文问答卡片过一遍即可，不必从头学。

### 5.3 LLM 系统设计（准备 3 个可讲 30 分钟的设计）

用统一模板：需求澄清 → 约束（成本/延迟/合规）→ 架构 → 关键取舍 → 评测方案 → 演进路线。备好：

1. 给银行合规部门设计企业 RAG（你做过，换成金融语境重讲）
2. 设计一个客服 Agent（工具设计、升级人工、评测）
3. 设计一套 LLM 应用的评测体系（从黄金集到线上监控）

### 5.4 行为面与银行性格问卷

- STAR 结构，8 个故事覆盖：冲突、赶工、失败、模糊需求、跨团队、为什么来香港、为什么这家公司、五年规划。
- 银行在线性格问卷**真的会挂人**（Jointaro 有 HSBC HK 真实案例）：答题一致性比"完美人设"重要，别试图反向工程问卷。
- 反问环节准备 3 个问题（团队做什么、怎么评价新人前 6 个月、LLM 落地目前最大的瓶颈是什么）。

|---|---|---|---|
| 银行科技 | 4-8 万 + 1-3 个月花红 | 60-120 万 | "HK$55-70K/month plus bonus, open to discussion" |
| 初创/数码港 | 3.5-6.5 万 | 45-90 万 | "HK$45-60K/month" |
| 大厂驻港 | — | 约 RMB 100-200 万 | 按总包谈，对标内地同级或略高 |
| 量化（冲刺） | — | 150 万+ | 不主动报数，问对方 band |

原则：**给 band 不给单点**；让对方先出 range；香港惯例谈月现金 + 花红月数，别只盯 base。你手中的 IANG 免担保身份 + 随时到岗，是谈判桌上真实的筹码——公司省下的不只是签证费，还有专才审批的 6-8 周不确定期。

## 8. 风险与备选方案

1. **12 月没拿到 offer**：签证到 2028-01，天没塌。降档动作：① 放宽到 ML Platform / Data Engineer / 后端+LLM 混合岗（你的平台经历完全够格，先进香港市场再内部转）；② 走 contract-to-perm（Randstad、Hays 等有银行合同工通道，门槛低、转正常见）；③ Cyberport 初创快速通道。
2. **红线时间点**：最迟 **2027 年秋**前必须就业（IANG 续签需雇佣证明，到期前 3 个月内、至少提前 6 周申请）。现在启动意味着你有整整一年容错。
3. **永居连续性**：因学生签与 IANG 之间存在无签证间隔，7 年时钟已从 IANG 激活日重新起算（约 2033 年初达标）。此后不能再有任何断档：换工作/续签无缝衔接，且真实以港为居住地、留存 MPF/税单/租约等在港定居证据。若人目前在内地，Phase 3 前后迁港最稳。
4. **方向错配风险**：香港的 Agent 岗多为工程落地型，纯 post-training/RL 研究岗极少。若你的核心诉求是 agentic RL 前沿，内地大厂/量化更对口——想清楚你要的是"香港的生活与身份"还是"算法前沿"，两者在香港只能取前者。
5. **心态**：香港招聘两极——初创几天走完流程，银行 3-5 周起步且中途静默很常见。永远平行推进多家，别单吊一个流程。
