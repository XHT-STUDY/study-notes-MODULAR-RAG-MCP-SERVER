# 通过社招进入大厂担任 Agent 算法工程师 / LLM 应用工程师：真实情况调研笔记

> 调研日期：2026-09-08（检索执行于 2026-09）
> 一句话总结：社招进入大厂 LLM/Agent 岗的主力画像仍是「名校硕士 + 2~5 年 NLP/搜广推经验（后端转 AI 应用是另一条平移通道）」，面试以「项目拷打 + 大模型八股 + 手撕注意力/中等偏上算法题」为主且二面最易挂，薪资仍处全行业第一梯队（大模型算法新发岗平均月薪约 7 万，头部 2-2/P7/L8 总包 100~150 万）但 2026 年起出现「核心人才天价、普通岗平薪/降薪」的结构性分化，工作强度普遍 9 点后下班、约三分之一从业者周工时超 60 小时。

- 【一手】= 发帖人本人经历（面经/offer/在职自述）

### 1.3 之前做什么方向（转型路径）

- 【二手】字节大模型算法 JD 明确接受「推荐系统、广告、NLP、CV 等方向深度学习背景」（上引 JD）——**搜广推/NLP 转大模型是最顺的路径**。
- 【二手】知乎《程序员如何转行到 AI 大模型领域》高赞观点：大部分程序员转大模型方向**不需要"转行"，需要的是"平移"**；后端/系统架构经验在 AI 应用岗直接复用（[zhihu.com/question/10260155433](https://www.zhihu.com/question/10260155433)）。
- 【二手】牛客《聊一聊现在的 AI 岗位——从别再无脑堆关键词开始》：**模型训练岗需求量远小于 Agent 开发和 AI Infra**，选方向要兼顾兴趣和市场需求（[nowcoder.com/discuss/866630067277856768](https://www.nowcoder.com/discuss/866630067277856768)）。
- 【二手】数百份 JD 分析文章：Agent 岗要求「智能体设计、多智能体协作、任务规划、工具调用」，**传统 NLP/搜索背景工程师转型有优势**（知乎专栏《AI 大模型求职真相》，[zhuanlan.zhihu.com/p/1896941040927212239](https://zhuanlan.zhihu.com/p/1896941040927212239)）。
- 【一手】反例参考：2026-03 牛客上一名**双非本科 golang 后端**（马鞍山学院）也进入了字节火山引擎一面，被问的全是 Agent 工具调用/MCP/ReAct——说明 AI 应用/Agent 岗对纯工程背景社招存在开口（牛客面经帖，2026-03）。

### 1.4 论文/竞赛/项目要求

- **应用层/Agent 岗**：面经显示考察重心是**项目落地与深挖**（见第三节），未见论文硬性要求；简历上"字节跳动大模型预训练"这类项目经历被视为跳槽强背书（知乎 Top Seed 讨论，上引）。
- **训练/研究岗**：顶会论文权重高。参考案例【二手】：美团北斗大模型岗 offer = 40K×15.5 + 40 万股票 + 5 万签字费，候选人背景 985 本硕 + **4 篇顶会**（牛客/脉脉转述，属校招 SP 档，可作研究岗门槛参照）。

## 二、年纪：28？32？35+ 还能进吗？

**未找到任何量化的年龄分布数据**。所获荣誉帖、面经帖作者几乎不写年龄，只能从「工作年限」间接推断主流人群约 **25~30 岁**（1.5~5 年经验）。

找到的年龄相关讨论：

- 【二手】知乎经典问题《算法工程师也会遇到 35 岁这道坎么？》观点两极：一派认为国内一线写代码/跑模型的工程师少、毕业生持续涌入加剧竞争；另一派（福井的回答）认为"35 岁危机是伪命题"（[zhihu.com/question/345939613](https://www.zhihu.com/question/345939613)、[zhihu.com/question/1981753739481203536/answer/1981759772597446362](https://www.zhihu.com/question/1981753739481203536/answer/1981759772597446362)）。
- 【二手】招聘方视角（自动驾驶算法 35 岁问题下）：35 岁危机最大问题是**候选人资历与公司期望不匹配**，而非年龄本身（[zhihu.com/question/510400633](https://www.zhihu.com/question/510400633)）。
- 【一手】知乎专栏《当一位 35 岁的算法工程师决定辞职读博》："35 岁是程序员绕不开的槛"，35 岁算法工程师选择读博突破瓶颈（[zhuanlan.zhihu.com/p/1962138341463012415](https://zhuanlan.zhihu.com/p/1962138341463012415)）。
- 【二手】知乎亦有「28 岁研究生毕业对 35 岁坎影响」的讨论（[zhihu.com/question/286047828](https://www.zhihu.com/question/286047828)）。
- 【二手】行业动态：**字节跳动被报道放宽 35 岁招聘年龄限制**，同时扩大毕业三年内青年招聘量、保持三年以上社招岗位占比 70%（知乎转述新闻，2025，[zhihu.com/question/1890422083986649707](https://www.zhihu.com/question/1890422083986649707/answer/1896126736955077008)）。

**结论**：大模型方向因为整体缺人，是近年对大龄社招相对友好的技术方向之一（有公司明文放宽年龄），但**35+ 拿到大厂大模型 offer 的一手成功案例帖未找到**。

## 三、面试情况：轮数、周期、考察内容、挂人环节

### 3.1 通用流程（多家公司高度一致）

【一手】知乎《2025 大模型算法工程师春季社招面试经验汇总》：流程几乎统一为——

> **自我介绍 → 项目拷打 → 通识考察 → 手撕代码 → 反问**

作者用约 **2 个月**面完 10 家公司（2025 上半年，[zhuanlan.zhihu.com/p/27537084854](https://zhuanlan.zhihu.com/p/27537084854)）。轮数上：2~4 轮技术面 + HR 面；字节豆包为**三轮技术面**，主题递进为「模型与推理优化 → 训练与对齐 → RAG 与产品思考」（【一手】掘金面经，2025 下半年，[juejin.cn/post/7595232643464134690](https://juejin.cn/post/7595232643464134690)）。

### 3.2 高频考察清单（综合多份面经）

**项目拷打**（决定印象的核心环节，【一手】牛客横扫帖）：
- 微调项目：业务背景 / 数据构成、是否用合成数据 / 训练方法选型理由（为什么不用别的方式、试过没有）/ 效果评估 / 如何处理幻觉 / 对通用能力的影响 / 为什么选这个基座。
- 应用层项目：整体架构、遇到的 bad case 及解决、数据指标如何定义与验证。

**通识/八股**（【一手】牛客横扫帖 + 知乎汇总 + CSDN 字节帖合并去重）：
- 架构类：Transformer 细节、BERT/RoBERTa 区别、注意力公式为何除以 √d_k（拼多多一面）、位置编码手推、MoE vs Dense 收益代价、Qwen 与 DeepSeek 特点（2026 高频，CSDN）。
- 训练类：SFT/DPO/RLHF 全链路、**PPO 与 GRPO 区别**（拼多多一面 2025-11）、过程奖励 vs 结果奖励、DeepSeek R1 蒸馏思路、合成数据方法。
- 系统/Infra 类：DeepSpeed ZeRO 三个 stage 的具体切分对象（CSDN 字节二面）、TP/PP 策略选择、TP=2 时 QKV 权重怎么切、TP 需要哪些通信算子、FlashAttention 为什么分块不损失精度（CSDN 字节帖）；OOM 排查、模型参数量估算。
- 推理类：vLLM 的 PagedAttention、KV cache、prefix cache、MLA、FlashAttention（美团二面）。
- RAG：RAG 流程与评估方法、RAG 幻觉来源、文档规范（字节火山一面）。
- 输出不可控处理：如何让模型稳定输出 JSON（牛客横扫帖通识题）。

**Agent 专属问题**：
- 什么是 Agent、Agent 与 workflow 区别（牛客横扫帖）。
- 工具调用设计：Agent 工具调用全流程、MCP 协议、ReAct 模式（【一手】字节火山引擎一面，2026-03，牛客）。
- 奖励函数设计：RL 训练系统中的 Reward 集成、Rollout/采样策略（字节豆包 JD 原文，[jobs.bytedance.com 火山方舟职位](https://jobs.bytedance.com/experienced/m/position/detail/7581491171309177093)）。
- 评测方法：多轮对话效果评测、Agent 任务成功率度量（小林 coding 面试题库归纳 Agent+RAG+工具调用覆盖 90% 一二面追问，[xiaolincoding.com](https://www.xiaolincoding.com/project/xiaolinnote.html)）。

**手撕代码**（难度中等偏上，算法题 + 模型代码双轨）：
- 手写多头注意力 / 手写位置编码（牛客横扫帖、知乎汇总）。
- LeetCode medium（DP 为主），字节部分部门到 hard（含贪心 DP）（知乎汇总）。
- 01 矩阵中找全 1 矩形（拼多多一面）、k 个一组翻转链表（美团二面）、合并区间（字节火山一面）。

### 3.3 挂人环节

- 【一手】CSDN 字节帖：C9 本硕 + 大厂 2 年，**一面通过、倒在二面**的基础拷问（DeepSpeed/TP 细节答不深）。
- 【一手】知乎汇总作者自述：字节面了两个部门，**一二面都没过，自评"基础不牢"**。
- 综合多帖：社招挂点最常见于**二面的项目深度追问与 Infra 八股**（一面手撕和 Transformer 基础反而是通过率较高环节）。

### 3.4 典型面经流程还原（6 份）

**① 知乎 · 2025 春季社招多公司串面**【一手】
- 背景：硕士、在职社招；周期约 2 个月；公司：腾讯、字节、拼多多、饿了么、顺丰、携程、金山、富途、TCL、虾皮。

- 链接：[blog.csdn.net/weixin_58753619/article/details/150934127](https://blog.csdn.net/weixin_58753619/article/details/150934127)。

**④ 牛客 · 拼多多大模型算法一面（2025-11-08）**【一手】

## 五、每天的工作内容：在职者自述

**自述 1（最详细的一份）**【一手】知乎《大模型算法工程师的日常工作是怎样的》Charlie 回答（2024-01，[zhihu.com/question/637791111/answer/3385576502](https://www.zhihu.com/question/637791111/answer/3385576502)）：
- **数据**：找数据 → 整理数据 → 清洗数据 → 看数据（无限循环）；
- **实验**：盯 loss/grad/ppl，训练异常分析；
- **分析**：实验结束做测评分析、结果是否符合预期、数据认知迭代；
- **Coding**：框架优化、数据处理、论文代码；
- **能力提升**：看论文、公众号、博客；
- **摸鱼**：聊微信、答知乎。
- 同问题下其他在职回答【一手】：「实验分析 + coding（框架优化、数据处理）」；「模型设计与研发、数据处理与预处理、训练、评测、部署」。

**自述 2（AI 应用工程师岗位生态）**【一手/准一手】掘金《聊聊我们公司的 AI 应用工程师每天都干啥》（团队落地 AI 产品两年后的分工观察，[juejin.cn/post/7512332419203727371](https://juejin.cn/post/7512332419203727371)）：
- AI 应用工程师是**介于"只会调大模型 API"和"大模型算法工程师"之间的生态位**，随 AI 产品增多从后端中分化出专职岗；不能只会 API 调用，但也不必深入底层模型技术。

**自述 3（岗位边界吐槽）**【一手/观点】知乎专栏《大模型应用算法岗和开发岗的界线在哪里》（[zhuanlan.zhihu.com/p/2039098311693578817](https://zhuanlan.zhihu.com/p/2039098311693578817)）：
- 应用算法岗现实困境：「写 prompt 又好像在和产品抢活干」；判断「岗位会减少但不会消失」。

**JD 佐证（可反推日常）**：
- 字节评测方向岗【二手 JD】：评测框架设计、评测模型训练/部署/调优、bad case 问题归因（牛客转发的字节 JD）。
- 字节豆包 RL/Agent 岗【二手 JD】：基于 Ray 的 RL Trainer 拓展、Rollout/采样策略、Reward 集成、Agent Loop 开发（字节官网 JD，上引）。
- 小红书 AI 应用研发岗【二手 JD】：对话交互、上下文管理、信息处理、业务流程模块开发优化（小红书校招官网）。
- JavaGuide 归纳 AI 应用工程师工作内容【二手】：RAG 知识库、Prompt 调优、Agent 工具调用、评测和稳定性保障（[javaguide.cn](https://javaguide.cn/roadmap/backend-to-ai-agent-roadmap.html)）。

**综合**：日常 = 数据/评测集建设（占比高）+ 训练/调优实验 + Agent/RAG 工程开发 + 稳定性保障；纯 prompt 调优被认为壁垒低，正在向 Agent 开发、评测体系、Infra 演进。

## 七、发展前景：晋升、风口还是泡沫、对 30+ 的建议

### 7.1 晋升路径与内部感受

- 【一手观点】牛客《拼多多 字节 二选一》帖：字节干活层级 1-2/2-1/2-2/部分 3-1，「**晋升不上去薪资就容易卡住，现在也做绩效分布，入职即巅峰很正常**」；并称"夕夕（拼多多）薪资比字节再高 50%，身边字节 3 年的同学一年 100w，他夕夕同学比他多多了"（[nowcoder.com/feed/main/detail/68fc58196a764f1db8e764633c53b21d](https://www.nowcoder.com/feed/main/detail/68fc58196a764f1db8e764633c53b21d)）。
- 内部转岗自由度：**未找到可靠的一手信息**（信息缺口）。

### 7.2 风口还是泡沫（从业者讨论）

- 【一手吐槽】GitHub《FAQ_Of_LLM_Interview》作者："大模型这方向真的卷，新 paper、新模型，东西出得比我读的还快"（[github.com/aceliuchanghong/FAQ_Of_LLM_Interview](https://github.com/aceliuchanghong/FAQ_Of_LLM_Interview)）。
- 【二手观点】知乎：算法岗此前泡沫使从业者基数变大，最卷的 CV 方向某些公司**录用比例 32:1**（[zhihu.com/question/490766338](https://www.zhihu.com/question/490766338)）。
- 【一手观点】知乎：「潮水退去不是说大模型像泡沫一样破裂，而是哪家公司适合做、哪家在骗钱会被很快看清」——泡沫挤出的是投机者而非行业（[zhihu.com/question/620385134](https://www.zhihu.com/question/620385134)）。
- 【二手】小红书算法岗在职者评价（经知乎专栏转述）：「薪资不错、快成长、强技术、好福利；缺点是高强度加班、高变动、强内卷」。

### 7.3 与传统算法岗（推荐/搜索）相比

- 【二手】极客时间专栏分析：预训练/后训练等核心研发岗集中在少数大模型公司，数量有限；多数人涌入的是应用层（[time.geekbang.org/column/article/936200](https://time.geekbang.org/column/article/936200)）。
- 【二手】JD 分析与牛客讨论：**Agent 开发与 AI Infra 的需求量大于模型训练岗**；传统 NLP/搜广推背景转 Agent 有优势；"这个方向最有技术含量"≠市场需求（知乎专栏《AI 大模型求职真相》；牛客《别再无脑堆关键词》帖）。
- 【一手佐证】2025 春社招汇总作者："DeepSeek 之后互联网和传统行业都开始投入 AI，机会和风险并存"——应用层坑位在向非大厂外溢。

### 7.4 「AI 岗会不会内卷饱和」

- 乐观派【二手】：《大模型时代还需要这么多算法工程师吗》——"用轮子/改轮子"（应用、微调、部署）仍需大量工程师（[zhihu.com/question/1895261168513294492](https://www.zhihu.com/question/1895261168513294492)）。
- 谨慎派【二手】：2025 届大模型工程师起薪约 14-17K×14 薪，与资深工程师差距巨大，"高薪属于有经验者和顶尖人才"（JD 分析文章）——新人红利期已过、门槛快速抬升。
- 岗位演化【二手】：纯"提示词工程师"作为独立岗位热度已明显消退（人人都是产品经理、水源资本等评论），向 Agent 开发/评测/Infra 收敛。

### 7.5 对 30+ 从业者的建议（社区主流声音）

- 35 岁问题的主流归因是「**资历与期望薪资不匹配**」而非年龄本身；建议走技术专家路线、管理路线或创业（知乎多个 35 岁讨论帖，上引）。
- 极端案例参考：35 岁辞职读博重塑竞争力（知乎专栏，上引）。
- 字节等公司 2025 年起放宽 35 岁招聘限制，对应聘者是边际利好（知乎转述新闻，上引）。
- 注意：以上均为观点类内容，**未找到 35+ 成功入职大模型岗的一手面经**。
